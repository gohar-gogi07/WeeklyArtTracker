# WeeklyArtTracker

# The goal of this project: help track weekly hours spent drawing to hopefully encourage/motivate me to draw more. The program allows the user to log daily the amount of time they spent drawing that day and what materials they used. At the end of the week, the program will the provide a summary of the user's weekly statistics. Something of this sort:

# Week of MM/DD/YY to MM/DD/YY
# ----------------------------
# Average hours spent drawing every day: ___ hrs/day
# Materials used: ____(MM/DD), ____(MM/DD), ____(MM/DD) ... 
# Overall score: __/10 (along with a score breakdown in parantheses)
